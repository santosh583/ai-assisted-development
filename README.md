
# AI Student Helper

A beginner-friendly Python project for learning Git and GitHub.

## Features

- Asks the user for their name.
- Prints a welcome message.
- Demonstrates a simple Python function.

## Requirements

- Python 3.10 or later

## Run the project

Open a terminal in this folder and run:

```bash
python app.py
```

If Python is not recognized on Windows, try:

```bash
py app.py
```

## Learning Goals

- Git initialization
- Staging and commits
- Connecting a local repository to GitHub
- Pushing code to GitHub
- Branching and project history
- README documentation and AI-assisted code review
